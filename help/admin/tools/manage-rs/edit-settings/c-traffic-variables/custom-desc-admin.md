# カスタムレポートの説明

eVar、prop、分類、イベントにカスタムレポートの説明を提供できます。 すべてのエンドユーザーが説明を確認できます。

**[!UICONTROL Analytics]**／**[!UICONTROL 管理者]**／**[!UICONTROL レポートスイート]**／**[!UICONTROL 設定を編集]**／**[!UICONTROL *変数&#x200B;*]**

>[!NOTE]
>
>従来のほとんどの分類に対して説明を追加できますが、現時点ではモバイル分類では利用できません。

![](/help/admin/tools/assets/report_descriptions.png)

1. レポートの説明を入力します。 最大文字数は255文字です。
1. 「**[!UICONTROL 保存]**」をクリックします。

説明は、次の2つの場所に表示されます。

* そのレポートのタイトルバーに、次の操作を行います。

  ![](/help/admin/tools/assets/report_description_2.png)

* 左側のナビゲーションのレポートにカーソルを合わせると、ツールのヒントとして以下が表示されます。

  ![](/help/admin/tools/assets/report_description_3.png)
