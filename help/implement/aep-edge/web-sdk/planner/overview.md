# Web SDK migration planner

Web SDK migration plannerは、Adobe Experience Platform Web SDKへのAdobe Analytics tags拡張機能の移行を計画および実行するのに役立ちます。 Adobe Experience Platform Data Collection内の単一のガイド付きワークスペースに移行できるので、既存のタグ実装からWeb SDKに、構造化された追跡可能な方法で移行できます。

>[!AVAILABILITY]
>
>ツールとドキュメントの両方が積極的に開発されています。 ドキュメントの提供は、2026年9月下旬を予定しています。
