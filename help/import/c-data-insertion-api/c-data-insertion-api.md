# データ挿入 API

[Data Insertion API](https://developer.adobe.com/analytics-collection-apis/methods/data-insertion/)と[Bulk Data Insertion API](https://developer.adobe.com/analytics-collection-apis/methods/bulk-data-insertion/)はどちらも、Adobe Analyticsにサーバーサイドの収集データを送信するメソッドです。 データ挿入 API 呼び出しは、一度に 1 イベントずつおこなわれます。 Bulk Data Insertion API は、1 行につき 1 件のイベントデータを含む CSV 形式のファイルを受け付けます。

サーバーサイドコレクションの新しい実装を行う場合は、AdobeでBulk Data Insertion APIを使用することをお勧めします。

エンドポイント、リクエストおよびレスポンス形式、および完全な変数参照については、Adobe Developerの[Data Insertion API](https://developer.adobe.com/analytics-collection-apis/methods/data-insertion/)および[Bulk Data Insertion API](https://developer.adobe.com/analytics-collection-apis/methods/bulk-data-insertion/)のドキュメントを参照してください。
